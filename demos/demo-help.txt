$ secretzero --help
Usage: secretzero [OPTIONS] COMMAND [ARGS]...

  SecretZero: Secrets orchestration, lifecycle, and bootstrap engine.

  SecretZero helps automate the creation, seeding, and lifecycle management of
  project secrets through a declarative, schema-driven workflow.

Options:
  --version  Show the version and exit.
  --help     Show this message and exit.

Commands:
  create        Create a new Secretfile from a template.
  drift         Detect drift between lockfile and actual targets.
  graph         Generate visual graph of Secretfile relationships.
  init          Initialize project by checking and installing provider...
  policy        Check secrets against policy rules.
  providers     Manage and introspect providers.
  rotate        Rotate secrets based on rotation policies.
  schema        Schema utilities for Secretfile.
  secret-types  List supported secret types and generators.
  show          Show information about secrets.
  status        Show synchronization status of secrets and targets.
  sync          Generate and synchronize secrets to targets.
  test          Test provider connectivity and authentication.
  validate      Validate Secretfile configuration.
