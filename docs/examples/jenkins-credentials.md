# Jenkins Credentials Example

This page highlights the Jenkins credentials example used in documentation.

## Source

The canonical example lives in the repository:

- https://github.com/zloeber/SecretZero/blob/main/examples/multi-cicd.yml

## Usage

```bash
curl -O https://raw.githubusercontent.com/zloeber/SecretZero/main/examples/multi-cicd.yml
cp multi-cicd.yml Secretfile.yml
secretzero sync
```
